# 내 취미 소개 - 조깅 (MY HOBBY · JOGGING)

## 作品名称
**내 취미 소개 - 조깅**（网页主标题：**바람을 가르며 달리는 즐거움, 조깅**）

## 作品用途
基于纯 HTML + CSS 制作的静态单页网站，用于展示个人兴趣爱好“慢跑（조깅 / Jogging）”，并以简洁直观的方式为初次接触慢跑的人提供入门指引。

## 主要功能（基于 `index.html` 页面结构）
1. **标题与一句话介绍（`header.hero`）**  
   展示 `🏃‍♂️ MY HOBBY · JOGGING` 徽章、主标题以及一句话简介（每天清晨 20 分钟，用轻快步伐唤醒身心的个人时间）。
2. **慢跑优势 Emoji 卡片 3 张（`조깅이 좋은 3가지 이유`）**  
   - `👟` **가벼운 시작**：无需昂贵装备或场地预约，一双舒适的运动鞋即可在家门口开跑。  
   - `🌅` **상쾌한 공기**：迎着晨光与微风奔跑，让思绪自然舒展。  
   - `💪` **꾸준한 활력**：即使短距离坚持，也能提升体能并带来一整天的活力。
3. **“如何开始这项爱好” 3 步骤指南（`이 취미를 시작하려면`）**  
   - `01` **편한 러닝화와 가벼운 복장 챙기기**：选择缓震合脚的跑鞋与吸汗轻便的运动服。  
   - `02` **집 근처 평탄한 코스 정하기**：预先选好附近公园或河边步道等少红绿灯、路面平整的 1~2km 路线。  
   - `03` **걷기와 천천히 뛰기 번갈아 하기**：初期采用“步行 2 分钟 + 慢跑 1 分钟”循环 5 次，重点是找到适合自己的呼吸节奏。
4. **纯静态与移动端友好**  
   `index.html` 配置了响应式 `viewport` 元标签且仅引入本地 `style.css`，不依赖任何外部服务器、登录或安装包。

## 运行方法
无需安装任何环境或启动服务器，直接双击 **`index.html`** 即可在默认浏览器中打开并浏览。
